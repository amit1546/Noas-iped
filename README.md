# היומן שלי 📔

אפליקציית ווב בעברית שעוזרת להתמיד: משימות יומיות, הרגלים, יומן תזונה עם יעד קלורי וארוחות קבועות, לוח שנה חודשי ודשבורד עם גרפים.

## מה יש בפנים
- **היום** — פס קלוריות וחלבון (יעדים שאפשר לערוך בלחיצה) (אכלתי / נשאר / יעד) ורשימת סימון ✓ צבעונית לפי סוג של כל מה שתוכנן להיום, מסודרת לפי שעות
- **תכנון** — מתכננים כל יום: משימות, אימונים, תזכורות (עם אפשרות להתראה ביומן הטלפון), ארוחות (גם לתאריכים קדימה; קלוריות וחלבון לא חובה; ארוחה קבועה יכולה להתאים לכמה זמנים) והרגלים; שעה היא תמיד רשות
- **לוח שנה** — תצוגה חודשית עם נקודות לכל יום (באותם צבעים כמו במסך היום), חלון פרטים ליום בלחיצה, וסימון ימי עבודה; לחיצה על יום פותחת את התכנון שלו
- **סיכום** — יומן אימונים, הרגלים, קלוריות, ומשקל גוף עם רישום שקילה ותזכורת שבועית
- **הגדרות** — יעדים, מצב כהה/בהיר, ייצוא וייבוא גיבוי

## איפה הנתונים נשמרים
בדפדפן של המכשיר (IndexedDB) — בלי שרת ובלי הרשמה. כדי לעבור למכשיר אחר: הגדרות → **ייצוא גיבוי**, שולחים את הקובץ לעצמך, ובמכשיר החדש הגדרות → **ייבוא גיבוי**.

## פיתוח
```bash
npm install
npm run dev     # שרת פיתוח
npm test        # בדיקות
npm run build   # בנייה ל-dist/
```

React + Vite + TypeScript, Tailwind, Dexie, Recharts, Framer Motion, PWA.
