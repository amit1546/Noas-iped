# היומן שלי 📔

אפליקציית ווב בעברית שעוזרת להתמיד: משימות יומיות, הרגלים, יומן תזונה עם יעד קלורי וארוחות קבועות, לוח שנה חודשי ודשבורד עם גרפים.

## מה יש בפנים
- **היום** — משימות והרגלים עם הוספה מהירה, וסיכום תזונה
- **לוח שנה** — תצוגה חודשית עם נקודות לכל יום (משימות, הרגלים, תזונה)
- **תזונה** — יעד קלורי שמגדירים ידנית, ארוחות קבועות שמסמנים ב"אכלתי", ארוחות חד-פעמיות, מונה "נשאר", משקל גוף
- **סיכום** — גרפים של 7 הימים האחרונים
- **הגדרות** — יעדים, מצב כהה/בהיר, ייצוא וייבוא גיבוי

## איפה הנתונים נשמרים
בדפדפן של המכשיר (IndexedDB) — בלי שרת ובלי הרשמה. כדי לעבור למכשיר אחר: הגדרות → **ייצוא גיבוי**, שולחים את הקובץ לעצמך, ובמכשיר החדש הגדרות → **ייבוא גיבוי**.

## פיתוח
```bash
npm install
npm run dev     # שרת פיתוח
npm test        # בדיקות
npm run build   # בנייה ל-dist/
```

React + Vite + TypeScript, Tailwind, Dexie, Recharts, Framer Motion, PWA.
