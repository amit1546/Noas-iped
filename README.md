# היומן שלי 📔

אפליקציית ווב בעברית שעוזרת להתמיד: משימות יומיות, הרגלים עם רצפים 🔥, יומן אימונים, יומן תזונה עם יעד קלורי וארוחות קבועות, ודשבורד עם גרפים.

## מה יש בפנים
- **היום** — מבט על כל היום במסך אחד
- **משימות והרגלים** — עדיפויות, דחייה למחר, רצף נוכחי ושיא, לוח חום של 5 שבועות
- **אימונים** — תרגילים, סטים, חזרות ומשקל, שכפול אימון קודם, יעד שבועי
- **תזונה** — יעד קלורי שמגדירים ידנית, ארוחות קבועות שמסמנים ב"אכלתי", ארוחות חד-פעמיות, מונה "נשאר", מים ומשקל גוף
- **סיכום** — גרפים של 7 הימים האחרונים
- **הגדרות** — יעדים, מצב כהה/בהיר, ייצוא וייבוא גיבוי

## איפה הנתונים נשמרים
בדפדפן של המכשיר (IndexedDB) — בלי שרת ובלי הרשמה. כדי לעבור למכשיר אחר: הגדרות → **ייצוא גיבוי**, שולחים את הקובץ לעצמך, ובמכשיר החדש הגדרות → **ייבוא גיבוי**.

## פיתוח
```bash
npm install
npm run dev     # שרת פיתוח
npm test        # בדיקות
npm run build   # בנייה ל-dist/
```

React + Vite + TypeScript, Tailwind, Dexie, Recharts, Framer Motion, PWA.
